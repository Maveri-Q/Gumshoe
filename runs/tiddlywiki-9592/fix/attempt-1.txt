The simplified `$tw.utils.getLocationHash` in `boot/boot.js` returned the raw browser hash, dropping the rule that ignores hashes starting with a second `#` (or `%23`), so clicking `##my-spot` was treated as navigating to a tiddler called `#my-spot`. I restored that rule (and the `#` result for an empty hash) while still using `window.location.hash`, and replaced the deprecation comment because the function is no longer equivalent to it; I had no way to run the app here, so your steps haven't been tested.
