The tag name input's `$keyboard` widget caught Ctrl+Enter (the `input-accept-variant` shortcut) and stopped it from propagating even though the tag picker has no action for it, so the editor's save shortcut never fired. In `core/wiki/macros/keyboard-driven-input.tid:137` I made the single widget listen for the accept, accept-variant and cancel shortcuts only when the caller supplies actions for them, which lets Ctrl+Enter through to save, also covers the field name input, and keeps the un-nested structure from #9235; I haven't run the app or the tests.
